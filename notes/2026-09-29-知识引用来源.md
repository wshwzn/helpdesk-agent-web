# 知识引用来源

## 实现功能

- AI 回答包含知识引用时，在消息气泡内展示“参考来源”卡片。
- 参考来源列表默认整体折叠，点击“参考来源”后展开，再次点击可以收回。
- 每条来源显示知识库名称、文件名、Chunk 序号和命中内容。
- 默认将片段压缩到 140 个字符；较长内容可以“展开完整片段”或收起。
- 流式回答完成后立即展示引用，重新进入对话后仍可从历史消息恢复。

## 新增文件

- `src/components/chat/KnowledgeSources.vue`：渲染知识来源列表并管理片段展开状态。

## 修改文件

- `src/types/conversation.ts`：增加知识引用类型和消息引用字段。
- `src/components/chat/ChatMessageList.vue`：在 AI 消息中挂载来源卡片。
- `src/views/ChatView.vue`：为流式回答占位消息初始化空引用数组。
- `src/styles/index.css`：增加来源卡片、片段内容和展开按钮样式。

## API 影响

依赖后端 `ChatMessageResponse.citations` 字段，不新增前端请求。

## 验证

- `npm run test`
- `npm run build`

## 已知限制

- 当前只能展开完整 Chunk，不能打开或定位原始 PDF、Word 文档。
