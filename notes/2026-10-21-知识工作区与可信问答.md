# 知识工作区与可信问答

## 实现行为与业务规则

将早期客服聊天入口重建为“知序 · 企业知识工作区”。采用暖纸色、墨色正文、陶土色操作按钮与鼠尾草色证据区，提供新提问首页、会话导航、结构化回答和引用侧栏；登录注册页同步品牌。员工端沿用原 Vue/TypeScript、鉴权、HTTP 与 SSE 基础，不创建新仓库，不增加依赖。

- 所有新提问走 KNOWLEDGE，发送成功进入 start 时才清空草稿；首次发送前不创建空会话。
- 回答以 done 返回的完整落库消息为准，不提前展示 delta 正文。等待期间只说明正在检索与核验，不编造具体进度。
- 来源只列出 claims 和 conflicts 实际引用的证据；未引用的检索候选不冒充答案来源。点击证据显示对应引用原文、版本、范围、快照时间和完整片段。
- 技术失败、资料不足、冲突、条件不完整分别显示。旧消息没有报告时明确标注未附核验报告。
- 范围卡片只能使用后端选项，最多三项；禁止空选、重复、未知范围和 ALL。只有最新完成的澄清卡片允许续答，旧卡片只读。刷新后根据续答关系恢复已选择范围。
- 会话与消息分页；消息初始显示最后一页，支持加载更早消息。切换请求使用序号隔离迟到响应。
- 停止等待只中断浏览器请求；本地 CLIENT_CANCELLED 和后端 STREAM_CANCELLED 使用一致标签。后台仍可能完成，重新打开时以持久化结果为准。回填问题仅恢复编辑框，不自动重新调用模型。
- 删除对话前确认，后端归档成功后更新列表；当前聊天页停止加载旧工单操作。

## API 与数据库

没有后端接口、模型配置、默认知识库或数据库变更。复用现有认证、会话与 SSE 接口。续答请求使用已有 `clarificationMessageId`、`applicabilityScopes` 字段；旧工单文件暂存但不接入新页面。

- 最终完整刷新后检查浏览器日志，无新增 error/warn；澄清已选范围和证据侧栏恢复正常。
- 本地真实登录、首页、历史会话、来源展开、帮助弹窗，以及 390×844 窄屏导航与阅读布局检查。
- 真实新提问“普通员工因公出差，每晚住宿报销上限是多少？”触发上海/北京范围卡片，多选续答后显示当前练习库的上海 600 元、北京 450 元；原文来源可展开。刷新后两项仍显示已选择，旧卡片不可再提交。
- 读取历史 entry-eval-E04 的版本引用、scope-eval-E05 的技术失败，失败不显示被拒绝的答案草稿。
- 取消验证共发起两次请求：第一次在点击前已完成，第二次成功停止前端等待并恢复输入；重新读取历史发现后端已完成该回答，符合“停止等待”的边界。加上前面的提问和续答，本轮共四次实际生成请求，不把它们作为后端质量评测结果。
- 浏览器截图保存在本机被忽略的 `artifacts.local/`，不提交账号信息、令牌、环境变量、运行日志或构建产物。

## 已知限制与后续

- 本轮只有员工端；管理端需后续按同一视觉体系重建。
- 搜索仅限已加载会话；未对超过一百条消息的长会话执行浏览器翻页压测。
- 窄屏为浏览器视口验证，未覆盖真实手机键盘、所有浏览器和辅助技术。
- 本轮未重新注册账号或删除现有会话，保留既有鉴权与归档接口。
- 不新增后端阶段进度、任意追问记忆或取消模型计费能力；回答质量与耗时仍由现有后端链路决定。
