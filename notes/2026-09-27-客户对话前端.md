# 客户对话前端

## 实现功能

- 创建独立的 Vue 3 + TypeScript + Vite 客户前端项目。
- 支持客户注册、登录、退出和路由登录校验。
- 支持新建、切换对话以及加载历史消息。
- 通过 `POST SSE` 接口逐段显示 AI 回复，并处理开始、增量、完成和失败事件。
- 提供桌面端与窄屏自适应的客户聊天界面。

## 主要文件

- `src/views/LoginView.vue`、`RegisterView.vue`：认证页面。
- `src/views/ChatView.vue`：客户对话主页面和流式状态管理。
- `src/components/chat/`：对话侧栏、消息列表和输入框。
- `src/api/`：认证、对话及 SSE 请求封装。
- `src/stores/auth.ts`：登录状态管理。
- `src/router/index.ts`：页面路由和登录守卫。
- `src/styles/index.css`：全局视觉样式和响应式布局。

## 接口影响

前端消费后端已有的 `/api/auth/**`、`/api/conversations/**` 接口，没有修改后端接口或数据库表。开发环境通过 Vite 将 `/api` 代理至 `http://localhost:8080`。

## 验证

- `npm run test`：验证 SSE 分片、多行数据、错误响应及无尾随空行场景。
- `npm run build`：执行完整类型检查和生产构建。
- 本地开发服务器：验证页面资源可正常访问。

## 已知限制

- 当前未实现工单、人工客服和管理端页面。
- 历史消息暂按后端第一页最多 100 条展示。
- SSE 中断后提示失败，暂不自动重连或重新生成。
- 登录令牌暂存于浏览器 `localStorage`，正式部署前需调整安全方案。
- 当前执行环境没有可用图形浏览器，本轮未完成截图式视觉验收。
