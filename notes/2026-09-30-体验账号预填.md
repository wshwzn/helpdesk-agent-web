# 客户端体验账号预填

## 实现功能

- 客户端登录页默认填入体验账号 `user` 和密码 `user123`，访问者可以直接点击登录。
- 输入框仍可正常编辑，用户可以覆盖预填内容并登录其他客户账号。

## 修改文件

- `src/views/LoginView.vue`：调整登录表单初始值。

## API 影响

没有新增或修改后端接口、数据库表及请求结构。

## 验证

- `npm run test`：2 个测试文件、7 项测试通过。
- `npm run build`：TypeScript 类型检查和生产构建通过。

## 已知限制

- 预填凭据会包含在公开的前端构建产物中，因此该账号只能作为权限受限的公开体验账号，不能拥有管理员或敏感数据访问权限。
